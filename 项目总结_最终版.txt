一、项目结论(一句话)
----------------------------------------------------------------
用 LightGBM + 5年数据 + 特征,预测"未来30天是否跑赢沪深300",
只买预测概率最高的20%(Q5),每30天换仓,能稳定跑赢大盘。

    相对 Rank IC +0.107(信号有效,相对收益口径)
    IC>0 占比 82%(信号稳定)

    —— 2026-08-28 新增"市值+行业中性化"后,信号质量大幅提升 ——
    信号质量基准(绝对标签) ICIR : +0.517 → +0.821 (+59%)
    多空(Q5-Q1)超额 : +1.03% → +2.42%/期(翻倍以上)
    分层收益从"不单调"变为"完美单调"(Q5>Q4>Q3>Q2>Q1)

    —— 2026-08-28 再接"估值因子 PE/PB/PCF"后,相对 Rank IC 再上台阶 ——
    相对 Rank IC : +0.122 → +0.187 (+53%)
    ICIR        : +0.787 → +1.242 (+58%)
    多空 Q5-Q1  : +1.60% → +4.37%/期(翻倍以上)


----------------------------------------------------------------
二、探索历程(踩过的坑与关键转折)
----------------------------------------------------------------
1. 起点:15个技术指标 + LSTM/LightGBM,方向准确率 47%,看似接近随机。

2. 转折1 — 换评估视角:
   方向准确率(47%)掩盖了真实信号。改用横截面 Rank IC(排序能力)
   评估后,发现 1年训练 的模型是"稳定反向指标"(Rank IC = -0.069):
   预测涨的股票短期反而跌(均值回归)。

3. 转折2 — 5年扩张训练:
   把训练数据从1年扩到5年(跨牛熊),反向指标转正(Rank IC +0.073)。
   结论:1年的"反向"是小样本过拟合的假象。

4. 转折3 — 加特征(15→22):
   新增 RSRS阻力支撑、振幅、多周期波动率、长动量、量能结构。
   方向准确率不变(已到55%天花板),但 ICIR 0.44→0.51、
   IC>0 占比 51.6%→61.3%,信号更稳定。
   教训:RSRS 标准化窗口 m=250 会吃16%样本导致变差,m=60 才是对的。

5. 转折4 — 拉长周期(5天→30天):
   5天受"超买回落"均值回归干扰,拉长到30天后动量转正:
   Rank IC +0.076→+0.091、IC>0占比 61%→83%、多空胜率 55%→67%。

6. 神经网络对比(结论:不换模型):
   同数据下 LightGBM 55.17% > GRU 53.44% > MLP 53.05% > LSTM 52.76%。
   15个技术指标是低维表格数据,LightGBM 天生更强,神经网络无优势。

7. 多空回测(结论:只做多,不做空):
   多空(Q5多/Q1空)纯 alpha 仅 +0.47%/期,扣双边成本0.6%后变亏。
   A股做空受限 + alpha太薄,多空不成立。只能做"纯多头 Q5"。

8. 幸存者偏差检验:
   用2026当前成分股回测2024,系统高估收益。
   剔除19只次新股后,年化 28.56%→26.05%(缩水仅2.5pp)。
   结论:真实超额约 +10%/年,偏差不大但必须剔除次新股。

9. 转折5 — 相对收益标签(最关键的一次提升):
   把标签从"未来涨跌"改成"未来是否跑赢沪深300",
   并加入超额收益特征(个股收益-指数收益)。
   结果:多空超额从 -0.19% 转正到 +0.92%,相对 Rank IC +0.085→+0.107。
   原理:绝对标签模型在"猜大盘"赚beta;相对标签才逼它学"谁比市场强"。

10. 转折6 — 市值+行业中性化(2026-08-28,往"真量化"靠拢的第一步):
   发现原有信号里混着一大块"行业/市值 beta"(所以分层收益不单调)。
   新增市值因子(size) + 行业分类 + 横截面中性化管道
   (去极值1/99分位 → z-score → 对[行业哑变量+log市值]回归取残差)。
   信号质量基准(evaluate_cross5y.py,绝对标签):
     ICIR        +0.517 → +0.821 (+59%,信号稳定性大幅提升)
     Rank IC     +0.091 → +0.116
     多空Q5-Q1   +1.03% → +2.42%/期
     分层收益    不单调 → 完美单调(Q5>Q4>Q3>Q2>Q1)
   结论:剥离行业/市值 beta 后,剩下的才是纯选股 alpha,更纯更稳。

11. 转折7 — 估值因子 PE/PB/PCF(2026-08-28,价值因子的力量):
   百度估值接口实测只支持5个指标(总市值/市盈率TTM/市盈率静/市净率/市现率),
   股息率/ROE/EPS 等全部返回空。于是接入能拿到的三个价值因子
   pe_ttm/pb/pcf,取 log(负值置NaN)后进横截面中性化管道。
   A/B 评估(相对标签口径):
     Rank IC     +0.122 → +0.187 (+53%)
     ICIR        +0.787 → +1.242 (+58%)
     多空Q5-Q1   +1.60% → +4.37%/期
     分层收益    完美单调 Q5+3.68%>Q4+1.55%>Q3+0.54%>Q2-0.05%>Q1-0.68%
   结论:低 PE/PB/PCF 的价值因子在 A 股横截面极有效,
        推荐榜变银行/券商/电力等低估值价值股,回避榜是高估值成长股(茅台/宁德/迈瑞)。

三、最终方案
----------------------------------------------------------------
【数据】
  - 沪深300成分股,约300只,5年日线(2021-01 ~ 2026-08)
  - 日线数据源:akshare 新浪源 stock_zh_a_daily(带 sh/sz/bj 前缀,前复权)
  - 本地缓存:cache/{code}.csv(增量更新)
  - 基本面数据(2026-08-28 新增):
      行业 = 新浪"行业"板块(84个,覆盖264/300≈88%,缓存 _industry_map.csv)
      市值 = 百度估值(逐股点-in-time总市值,覆盖300/300,缓存 _mktcap_panel.csv)

【特征】29个(22技术 + 3超额 + 1市值size + 3估值)
  原始22个:ret_lag1~5/10/20、ma_ratio_5/20/60、macd三要素、
           rsi、boll、vol_5/20/60、volume_ratio、volume_ma_ratio、
           amplitude、rsrs
  超额3个:excess_5/20/60 = 个股N日收益 - 沪深300 N日收益
  市值1个:size = 行业中性化的 log市值(2026-08-28 新增)
  估值3个:log_pe_ttm/log_pb/log_pcf = 市盈率(TTM)/市净率/市现率取对数
          (2026-08-28 新增,负值置NaN)

【特征处理】(2026-08-28 新增,见 cross_section.py)
  横截面中性化,逐交易日进行(无未来数据泄露):
    去极值(1%/99%分位截断) → z-score → 对[行业哑变量 + log市值]回归取残差

【标签】
  target = 个股未来30日收益 是否 > 沪深300未来30日收益(跑赢大盘)

【模型】
  LightGBM 分类器,n_estimators=150, learning_rate=0.05, num_leaves=31
  pooled 训练(全部股票5年数据一起训,不按单只股票分开)

【策略】
  纯多头 Q5:只买"跑赢概率"最高的20%(约60只),等权持有30天换仓

【代码结构】
  config.py        全局配置(周期/成本/路径/随机种子)
  data.py          日线数据层(新浪源+增量缓存)
  features.py      技术指标特征(22个)
  fundamental.py   基本面数据层(新浪行业 + 百度市值)      ← 2026-08-28 新增
  cross_section.py 横截面中性化管道                      ← 2026-08-28 新增
  models.py        LSTM/GRU 等神经网络(实验用)
  evaluate_cross5y.py  横截面 Rank IC + 分层回测评估(信号质量基准)
  recommend_q5.py      最终选股工具(输出Q5买入榜+Q1回避榜)
  backtest_ls.py / score_pnl.py / relative_alpha.py  回测与多空检验

五、核心经验(为什么之前会走弯路)
----------------------------------------------------------------
1. 评估指标错了会掩盖真实 alpha:
   方向准确率(47%~52%)看起来很弱,但 Rank IC 显示信号真实存在。
   选股看的是"排序能力",不是"猜对涨跌"。

2. 小样本过拟合会产生"反向指标":
   1年训练导致 Rank IC=-0.069(反向),5年训练才转正。
   数据量是修复过拟合的关键,不是调模型。

3. 选股本质是"相对强弱",不是"绝对涨跌":
   绝对标签模型在偷懒"猜大盘"(赚beta),
   相对标签(跑赢大盘)才逼它学真本事(赚alpha)。
   这是本项目最大的提升点。

4. 神经网络不必然优于树模型:
   低维表格数据 + 中等样本量,LightGBM 就是最优解,别迷信深度学习。

5. 幸存者偏差必须检验:
   用当前成分股回测历史会虚高收益,剔除次新股后缩水约2.5pp。

6. 行业/市值暴露会污染 alpha(2026-08-28 新增):
   不中性化时,模型靠"大盘蓝筹最近强"这种风格beta也能得分,
   分层收益不单调。中性化剥掉 beta 后,纯选股 alpha 才显现,
   ICIR 0.52→0.82、分层收益变完美单调。

7. 价值因子(低估值)在 A 股很值钱(2026-08-28 新增):
   接入 PE/PB/PCF 后 Rank IC 0.122→0.187、ICIR 0.79→1.24、
   多空超额 1.60%→4.37%/期。"便宜"是 A 股横截面最强的 alpha 之一;
   而基本面数据源受限(ROE/股息率拿不到)是当前最大的天花板。

----------------------------------------------------------------
七、局限与风险(诚实说明)
----------------------------------------------------------------
1. 幸存者偏差残留:拿不到历史成分股名单,只能剔除次新股,
   "被调出成分股"的偏差无法完全消除,真实收益可能再略降。

2. 样本期较短且偏牛市:回测仅 2024-02~2026-08(约30期),
   同期沪深300涨42%,模型未经历完整熊市考验。

3. 做空不可行:A股个股融券难、利息高,"多空"只是纸面,
   实盘只能做"纯多头 Q5",熊市里无法对冲。

4. 未计成本:冲击成本、停牌/涨跌停无法成交、滑点等
   实际交易成本可能高于回测假设的0.3%。

5. 行业分类覆盖不完整(2026-08-28 新增):
   东财/申万/乐咕数据源被限流或宕机,只能退而用新浪"行业"分类,
   约12%(36/300)的股票归入"未知"行业,中性化对其不精确。
   市值用百度估值,300只全覆盖,这一块没打折扣。

6. 已接入估值因子 PE/PB/PCF(2026-08-28),但 ROE/盈利质量/成长/股息率等
   财务因子仍无可用数据源(百度估值接口仅支持5个估值指标,东财/乐咕/申万
   均限流或宕机)——这是当前因子库的最大缺口。

7. 仅技术面+市值+行业:不含消息面/资金面/另类数据,黑天鹅无法预测。

8. 免责:本报告仅为模型信号演示,不构成投资建议,据此操作风险自负。
